# Testing

Real **Chromium** (Playwright) opens the real pages from disk — `file://` — exactly as a customer's browser would, with the network faked:

| Faked | How | Why |
|---|---|---|
| CDN libraries (pdf-lib, pdf.js, JSZip, heic2any) | answered from `tests/node_modules` (same versions as the pages) | no internet needed, deterministic |
| Google Fonts | blocked | results must not depend on web fonts |
| Apps Script backend | `FakeBackend` records every order and answers `S105` | no real orders, and we can inspect the PDF that was *sent* |
| The printer | a fake `SumatraPDF` script that logs its arguments | nothing is printed |
| Photos / PDFs | generated by `make_fixtures.py` (checkerboards, shadowed certificates, HEIC…) | the right answer is known exactly |

## Run
```bash
pip install -r tests/requirements.txt && python3 -m playwright install chromium     # once
(cd tests && npm install)                                                            # once
python3 tests/run_all.py            # all (~4 min)
python3 tests/run_all.py --fast     # no browser: structure rules, tools, listener (~25 s)
python3 tests/run_all.py --only scan_vertical
python3 tests/run_all.py --slow     # + 54-megapixel photo and 6 huge noisy photos
```
Linux/CI also needs `fonts-liberation` for the ₹ test (it skips itself politely if missing).

## What each suite protects
| Suite | Checks | Protects |
|---|---|---|
| `test_site_structure` | rules | dashboard button per page, `noindex` on private tools, sitemap/robots/CNAME/Google file, dev folders not published, **no secrets** |
| `test_tools` | tools | `new_page.py` (button + noindex + sitemap), `verify_live.py` |
| `test_listener` | shop PC | config file (even with a Notepad BOM), correct printer + settings, `PRINTED`/`ERROR`, wrong secret, refusal of template defaults |
| `test_smoke_pages` | every page | opens, title, no JS errors, no sideways scroll on a phone, dashboard toggle |
| `test_print_pdf` | /print/ | Gujarati⇄English, preview + zoom, page selection, **price maths**, the order that is sent (only chosen pages), errors, phone |
| `test_print_photos` | /print/ | photo editor: EXIF rotation, styles, A4 PDF, multi-photo, edit-again, cancel, errors, phone |
| `test_print_layout` | /print/ | order-received screen on tiny phones, footer never covering Send, **₹ glyph on a PC with no ₹ in its fonts** |
| `test_scan_corners` | /scan/ | turn buttons, Straighten line, dots follow the photo, the scan follows what you see, laptop + phone |
| `test_scan_vertical` | /scan/ | the upright Vertical slider: straightens a squeezed page (ratio → 1.00), frame behaviour, speed |
| `test_scan_open` | /scan/ | JPG/PNG/HEIC, broken files, transparent PNG, locked-down preview windows |
| `test_aadhaar` | /aadhaar-card/ | open PDF (+ password), Scale text, Burn, undo |

## Writing a test
```python
from common import *                          # Report, browser(), new_context(), open_page(), fx(), canvas_image() …
rep, errors, be = Report("My page"), [], FakeBackend()
with browser() as b:
    ctx = new_context(b, be)                  # kind="phone" for a touch phone; (1366, 768) for a size; old_pc_fonts=True on browser()
    p = open_page(ctx, "my-page/index.html", errors)
    rep.check("title is right", p.title() == "…")
sys.exit(rep.finish(errors))                  # also fails on any JavaScript error
```
Add the file to `SUITES` in `run_all.py`. Prefer **measuring pixels or geometry** (canvas data, bounding boxes, PDF contents) over only checking that elements exist.

## Pitfalls we already hit
* `inner_text` honours CSS `text-transform` (our buttons are shown in capitals) → use `text_content` for exact text.
* Playwright's sync API cannot be started twice at once → open the old-PC-fonts browser *after* the first one closes.
* `localStorage` works on `file://` pages; each new context starts empty.
* Phone gestures: dispatch touches through a CDP session (`Input.dispatchTouchEvent`); scroll the target into view first or the touch lands outside the screen.
* Don't edit the file a test server is serving and then "compare" — compare two separate copies.
* A measuring row that lands on grey (outside the checkerboard) returns `nan` → measure the top-most / bottom-most rows that actually show the pattern.
